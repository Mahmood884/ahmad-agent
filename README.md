# Ahmad Agent

Local-first governed AI agent runtime.

## Architecture

Intelligence
→ Orchestration
→ Governance
→ Execution Gateway
→ System

## Core Principle

Agent intelligence must never equal system authority.

## Current Version

0.1.0 — Foundation

## Current Components

- Agent identity
- Request router
- Governance boundary
- Default-deny execution gateway
- Memory interface
- Skills directory
- Tools directory
- Agents directory
